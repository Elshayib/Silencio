# Desktop test release

Deliver one Windows x64 installer that bundles the app, native dependencies,
models, and the licensed VB-CABLE package. Automatically select physical
speakers, route playback, start at sign-in, and restore ordinary playback
on exit or crash. Driver elevation and a possible restart remain Windows
requirements. The owner confirmed distribution rights and requested an
unsigned test release rather than signing a public release.

The implementation and installer are present. See `docs/RELEASING.md` for
verification and the checks still required before a public final release.
